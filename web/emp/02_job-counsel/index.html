직업상담기록지 정리

상담하면서 적은 메모를 붙여넣고 정리하기를 누르면 양식에 맞게 채워집니다.

예) 정회근 93.8.27 / 10.15 내방 / 장안면 3.1만세로 270-12 / 지적 심한 / 몸 건강, 자격증 없음 / 직무 시간 급여 다 상관없음, 집 근처 / 복지관처럼 시설 안에서 일하고 싶다고 함 / 10월 일자리사업 추가모집 연계 예정

정리된 양식의 글자를 눌러 바로 고칠 수 있습니다. 상담방법은 항목을 눌러 선택합니다.

참여자 관리 DB에 저장

양식 내용을 확인한 뒤 누르면 구글 시트 "고용지원사업 참여자 관리 DB"의 구직상담 탭에 한 줄로 들어갑니다.

이름과 생년월일로 참여자를 알아서 찾습니다. 처음 오신 분이면 새 참여자로 추가할지 물어봅니다.

등록번호 직접 적기 (보통은 비워 두세요)

복사 후 한글 문서에 붙여넣으면 표 그대로 들어갑니다.
