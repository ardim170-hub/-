# 아르딤 취업지원 CRM

화성시아르딤복지관 직업지원팀이 쓰는 장애인 취업지원 업무 관리 웹 앱입니다.
천제사 "거래처 관리 CRM" 프롬프트를 바탕으로, 매입·매출 대신 **사업체 개발 · 명함 · 네트워크**를 관리하도록 바꿨습니다.

## 중복 찾기 · 합치기

사업체·기관은 이름((주)·주식회사 표기 무시), 사업자번호, 대표 전화가 같으면, 명함은 휴대전화·이메일 또는 이름+소속이 같으면 **중복?** 으로 표시합니다. 목록 위 안내에서 겹치는 것만 모아 보고, 상세 화면의 **이쪽으로 합치기**로 빈 칸을 채우고 활동·일정·명함 연결을 옮긴 뒤 다른 하나를 지웁니다. 새로 등록할 때 비슷한 것이 있으면 먼저 묻습니다.

## 색 구분

메뉴마다 고유 색(대시보드 남색, 사업체 개발 노랑, 지도 초록, 명함 청록, 네트워크 검정, 일정 파랑, 연락이력 주황, 실적 보라, 출장·특근 남보라)을 옆 메뉴·화면 제목·선택된 탭에 씁니다. 기록 종류 색(사업체 노랑, 지원고용·현장훈련 빨강, 기관 검정, 복지관 금색, 명함 청록)은 지도·목록·명함 카드·상세 창에 똑같이 씁니다.

## 바로 써 보기 (파일 버전)

1. `dist/아르딤_취업지원.zip`을 내려받아 바탕화면에 압축을 풉니다.
2. 폴더 안의 **크롬으로 열기.bat**을 더블클릭하면 크롬으로 열립니다 (기본 브라우저가 엣지여도 크롬으로 열림). 회사 계정 크롬 프로필로 열리게 하는 방법은 폴더 안 `사용법.txt`에 있습니다.
3. 처음에는 **예시 데이터**가 들어 있습니다. 실제로 쓰기 전에 `데이터 관리 > 모든 데이터 지우기`를 누르거나, 엑셀로 한꺼번에 교체하세요.

지도 배경과 주소 검색은 인터넷에 연결되어 있어야 표시됩니다.

## 메뉴

| 메뉴 | 하는 일 |
| --- | --- |
| 대시보드 | 취업알선 사이트·복지관 홈페이지 **바로가기 버튼**, **달력**(날짜를 누르면 그날 일정), 오늘 확인할 일(지난 일정, 7일 이내 일정, 3주 이상 연락이 없는 진행 중 사업체), 담당자별 현황, 단계별 사업체 수, 월별 발굴·채용연계 추이, 최근 활동 |
| 사업체 개발 | 사진·PDF로 등록: AI 키가 있으면 AI가 읽고, 없으면 글자가 든 PDF(구인공고·전자 사업자등록증)는 상호·대표자·사업자번호·주소·전화를 직접 찾아 채웁니다. **개발대장 복사**: 공유 시트 '구인업체 개발 대장' 열 순서(등록일·업체명·주소·전화번호·대표명(담당자)·직종/직무·근무시간·복리후생·비고·실적 진행도·상담자)로 복사합니다. 발굴 → 접촉 → 방문상담 → 채용협의 → 채용연계 (보류) 단계로 관리합니다. **발굴 기간 필터**(이번 달, 지난 달, 월 선택 등)와 발굴일 열, 구·읍면동 필터가 있습니다. **파일로 등록**에서 엑셀·CSV 목록을 한꺼번에 올리거나(열 이름 자동 인식), 사업자등록증·구인공고 사진/PDF를 AI로 읽어 등록합니다. 상세 화면에 **한 줄 요약**, **기초 조사**(검색 바로가기, AI 인터넷 조사), **AI 3줄 요약**이 있습니다. 상시근로자 50인 이상이면 장애인 의무고용 인원(3.1%, 소수점 버림)을 자동으로 계산합니다. |
| 지도 | **길찾기**: 점을 누르고 "여기까지 길찾기"를 누르면 복지관(또는 고른 출발지)에서의 직선거리와 대략 시간(차·버스)을 보여 주고 지도에 점선을 긋습니다. 네이버 지도(자동차·대중교통·도보)와 카카오맵 길찾기로 바로 넘어갑니다. 색: **사업체 개발 노랑**, **취업 연계 주황(✓)**, **지원고용·현장훈련 진행 빨강**(사업체 수정의 체크 또는 활동 기록·출장 명령부에서 자동), **기관 검정**, **화성시아르딤복지관 금색 별**(늘 표시). 화성시 **4개 구(만세·효행·병점·동탄)** 로 나눠 봅니다. 지도에는 모두 표시하고, 옆 목록에는 **고른 달에 발굴한 사업체만** 구별로 보여줍니다(그 달 발굴은 지도에서 굵은 테두리). 분류 대기 명함도 회색 점으로 보이고, 눌러서 사업체/네트워크로 나눌 수 있습니다. **화성시 대시보드** 탭은 16:9·21:9·원래 크기 중 골라 비율을 맞춥니다. |
| 명함 관리 | 지도 팝업·사업체 상세에서 **명함 관리에서 보기**로 그곳 명함만 모아 봅니다. **명함 사진으로 등록**: 휴대폰으로 찍어 올리면 AI가 이름·직함·연락처·주소를 읽어 채우고, 소속이 같은 사업체·기관이 있으면 자동으로 연결합니다. 초성 검색(`ㄱㅈㅂ`), 전화번호 뒷자리 검색, 가나다 색인이 있습니다. 휴대폰 연락처 파일(vcf)로 저장할 수 있습니다. |
| 네트워크 | 복지관 홍보·협력 기관(공공기관, 복지기관, 학교, 경제단체, 언론, 후원·자원봉사, 의료기관)과 협력 내용, 홍보 방식, 활동 기록을 관리합니다. 위쪽 **분류 대기 명함** 목록에서 버튼 하나로 사업체 개발이나 네트워크에 등록하면 지도에도 바로 표시됩니다. |
| 일정 | 방문, 면접 동행, 행사 등의 일정을 목록과 달력으로 봅니다. |
| 연락이력 | 줄마다 **구인공고 주소**(고용24·알바몬·알바천국·사람인·잡코리아 등, 사이트 주소만)를 넣으면 **공고 보기 · 사이트 이름** 버튼으로 공고 글이 바로 열립니다(시트용 복사 열 순서는 그대로). 사업체 연락·방문을 한 줄씩 기록합니다 (날짜·방식·사업체명·전화번호·담당자·직종·결과·연락결과·상태). 처음 보는 사업체는 사업체 개발에 자동 등록됩니다. 공유 시트 `○월 연락이력`과 같은 열 순서로 **복사**하고, 반대로 시트의 연락이력을 **붙여넣어 한 번에 가져오기**도 됩니다. **보고용** 탭: 총 사업체 연락 수, 총 방문, 채용의향 있음, 방문 사업체 표(결과·현장훈련 유/무·절차)를 보고용 시트 모양으로 복사합니다. |
| 출장·특근 | 현장중심센터 월별 **관내출장 명령부**(이 달 방문 기록 불러오기, 방법·출장시간·출장복명·비고 입력, 동행 추가)와 **특근 명령부**를 만들고, 결재란(담당·팀장)이 있는 한글 서식 모양으로 인쇄·PDF 저장하거나 한글 표에 붙여넣도록 복사합니다. **담당자별 명령부**는 한 사람당 한 장씩 결재란을 따로 두어 인쇄하거나 한글·워드로 여는 파일(.doc)로 받습니다. 예전에 한글로 쓴 명령부(.hwp)는 **한글 명령부 불러오기**로 여러 달을 한 번에 가져옵니다 (이미 있는 줄은 건너뜀). |
| 실적 | 복지관 실적표(현장중심직업재활센터 / 고용지원사업)의 세부사업명으로 실적을 입력하고, 사업체·기관 활동 기록을 날짜·세부사업별로 자동 집계합니다. **[구글 시트용 복사]** 를 누른 뒤 구글 시트 `실적(기타)` 탭의 사업날짜(B열) 칸에 Ctrl+V 하면 사업날짜~비고 열이 그대로 들어갑니다. |
| 데이터 관리 | (공유 사이트) 관리자만 설정을 바꾸고, **사용할 수 있는 사람** 명단으로 접근을 제한합니다. 엑셀 내보내기·가져오기, 사진까지 담긴 백업·복원, 담당 직원과 소속, 대시보드 바로가기, AI 키, 화성시 대시보드 주소를 설정합니다. |

## 기초 조사 (사업체정보지 · 직무분석지)

사업체 상세 화면의 **기초 조사**에서 복지관 한글 서식과 같은 항목으로 작성합니다.

- **사업체정보지**: 사업체 현황, 편의시설, 작업장 환경(청결성·안전성·소음도·온도·조명), 교통편, 장애인 고용환경(상·중·하), 고용현황·복리후생, 구인·근로 조건, 근무 여건·급여. 처음 열면 이미 입력한 사업체 정보로 미리 채워집니다.
- **직무분석지**: 직무마다 한 장. 신체능력·인지·작업수행·변별력·사회성 요구도(①~④), 직무 수행과정, 과업 분석, 유의사항, 종합 소견.
- **보기·인쇄**에서 서식 모양으로 보고 인쇄하거나 PDF로 저장할 수 있습니다.

## 활동 기록과 실적

- 사업체·기관 상세 화면에서 활동을 기록할 때 **실적** 칸이 함께 나옵니다. 비워 두면 자동으로 정해집니다.
  - 현장중심직업재활센터: 사업체 활동 → 사업체개발, 채용연계 → 취업
  - 고용지원사업: 채용연계 전 사업체 → 고용자원개발, 채용연계된 사업체 → 사업체관리, 채용연계 → 취업확정, 네트워크 기관 → 고용네트워크
- 어느 실적표를 쓸지는 `데이터 관리 > 소속별 실적 분류표`에서 소속마다 정합니다 (기본: 장애인개발원 → 현장중심직업재활센터, 고용공단 → 고용지원사업).

## AI 도우미 (선택)

`데이터 관리 > AI 도우미`에 Claude API 키([console.anthropic.com](https://console.anthropic.com)에서 발급, 쓴 만큼 요금)를 넣으면 다음 기능이 켜집니다. 키가 없으면 이 버튼들은 보이지 않고 직접 입력으로 씁니다.

- 명함 사진 → 연락처 자동 입력
- 사업자등록증·구인공고 사진/PDF → 사업체 정보 자동 입력
- 사업체 인터넷 기초 조사 (웹 검색 후 회사 개요, 규모, 채용 공고, 장애인 고용 관련 내용, 출처 정리)
- 사업체 기록 3줄 요약

공유 사이트에서는 키가 구글 서버(스크립트 속성)에만 저장되고, 파일 버전에서는 그 PC 브라우저에 저장됩니다. 명함 사진과 사업체 정보가 AI 서비스로 전송되므로 기관 개인정보 지침을 확인하세요. AI가 만든 내용은 틀릴 수 있으니 저장 전에 확인하세요.

사용 모델은 `claude-opus-5-5`이고, 모델이 요청을 거절하면 다른 모델로 자동 재시도하는 옵션(`fallbacks: "default"`)을 켜 두었습니다.

## 직원 소속 구분 (장애인개발원 / 고용공단)

- `데이터 관리 > 담당 직원과 소속 사업`에서 직원마다 소속을 정합니다.
- 사업체·기관 목록의 **우리 담당** 열과 상세 화면에 담당 직원 이름과 소속(개발원/공단) 표시가 붙습니다.
- 화면 위쪽의 **보기 범위**에서 `전체 팀 / 장애인개발원 / 고용공단 / 직원 한 명`을 고르면 대시보드·목록·지도·일정이 그 범위로 바뀝니다. 검색은 항상 팀 전체에서 찾습니다.
- 대시보드의 **담당자별 현황** 표에서 소속별·직원별 사업체 수, 진행 중, 채용 인원, 기관 수, 이번 달 활동 건수를 비교합니다.

어느 화면에서든 `Ctrl + K`를 누르면 사업체명, 담당자 이름, 전화번호 뒷자리, 기관명으로 검색할 수 있습니다.

## 위치 지정

사업체나 기관을 등록할 때 다음 순서로 위치를 정합니다.

1. 주소만 넣고 저장해도 됩니다. 주소에서 읍·면·동(또는 반송동 같은 법정동, 동탄구 같은 구 이름)을 찾아 그 동네 중심에 먼저 표시하고, 인터넷 주소 검색으로 정확한 위치를 찾으면 자동으로 옮깁니다.
2. 직접 정하려면 **주소로 찾기**를 누르거나, **읍·면·동**을 고른 뒤 아래 지도를 클릭하거나 핀을 끌어서 옮깁니다.

주소 검색은 OpenStreetMap을 쓰기 때문에 도로명 주소를 못 찾을 때가 있습니다. 그때는 동네 중심의 대략적 위치로 남습니다.

4개 구의 읍·면·동 구분은 2026년 2월 출범 기준이며, 행정동 경계 데이터(2026-07-01)와 대조해 확인했습니다. 지도를 클릭해 위치를 찍으면 경계 데이터로 읍·면·동을 자동으로 채웁니다.

## 데이터 저장에 대해

- 데이터는 **지금 쓰는 PC의 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 다른 PC나 다른 브라우저에서 열면 데이터가 따로 보입니다. 팀원과 함께 쓰려면 `엑셀 내보내기`로 파일을 주고받으세요.
- 브라우저의 방문 기록이나 사이트 데이터를 지우면 함께 지워집니다. 정기적으로 엑셀이나 백업 파일로 저장해 두세요.

## 엑셀 양식

`데이터 관리 > 빈 엑셀 양식 받기`로 양식을 받을 수 있습니다. 시트는 `사업체`, `네트워크`, `명함`, `활동기록`, `일정` 다섯 개이고, 각 시트는 ID 열로 서로 연결됩니다.

- 명함의 `연결 구분(biz/net)`과 `연결ID`: 어느 사업체(biz)나 기관(net)의 담당자인지 나타냅니다.
- 활동기록·일정의 `대상 구분(biz/net)`과 `대상ID`: 어느 사업체나 기관의 기록인지 나타냅니다.
- `위도`와 `경도`가 비어 있으면 `읍면동` 열의 동네 중심 위치로 표시합니다.

- 배경 지도(인터넷 연결 시, 지도 오른쪽 위에서 선택): Esri 일반 지도·위성 사진, © OpenStreetMap 기여자, 브이월드(인증키를 넣은 경우).

## 개발자용

```
index.html        화면 틀
css/app.css       디자인
js/util.js        날짜·문자열 도구
js/hwaseong.js    화성시 행정동 경계 (29개 읍·면·동, 4개 구)
js/data.js        코드값(단계, 업종, 읍면동 좌표), 예시 데이터 생성
js/store.js       저장소(파일 버전: IndexedDB / 공유 버전: 구글 시트), 통계, 검색, 엑셀
js/map.js         Leaflet 지도
js/views.js       화면 렌더링
js/forms.js       등록·수정 폼
js/import.js      엑셀·CSV로 사업체 일괄 등록
js/survey.js      기초조사 양식 (사업체정보지·직무분석지) 입력·인쇄
js/ai.js          AI 도우미 (Claude API: 명함 읽기, 문서 읽기, 기초 조사, 요약)
js/app.js         라우팅, Drawer, 검색, 버튼 동작
vendor/           Leaflet 1.9.4, SheetJS 0.18.5
apps-script/      구글 Apps Script 서버 코드(Code.gs)와 매니페스트
docs/             공유 사이트 설정 안내
```

`index.html`을 브라우저로 바로 열어도 동작합니다. 수정한 뒤에는 `node scripts/build.mjs`를 실행하세요. 파일 버전(`dist/아르딤_취업지원.html`)과 공유 버전(`dist/apps-script/`)이 함께 만들어집니다.

같은 화면 코드가 두 버전에서 모두 돌아갑니다. `google.script.run`이 있으면(Apps Script 안에서 열리면) 공유 모드로 동작합니다.
