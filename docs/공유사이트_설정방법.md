# 팀 공유 사이트 만들기 (구글 시트)

팀 4명이 한 주소로 들어와 사업체·명함·기관을 함께 등록하고 보는 방법입니다.
데이터는 복지관 구글 계정의 **구글 스프레드시트 한 개**에 저장됩니다. 비용은 들지 않습니다.

처음 한 번만 설정하면 되고 10분 정도 걸립니다. 설정하는 사람을 아래에서 **관리자**라고 부릅니다.

## 준비물

- 관리자의 구글 계정 (복지관 업무용 계정을 권장합니다)
- 저장소의 `dist/apps-script/` 폴더에 있는 파일 두 개
  - `Code.gs`
  - `index.html`

## 1. 데이터를 저장할 구글 시트 만들기

1. [sheets.google.com](https://sheets.google.com)에서 **빈 스프레드시트**를 만듭니다.
2. 제목을 `아르딤 취업지원 데이터`로 바꿉니다.

시트 안의 칸은 비워 두세요. 사이트를 처음 열 때 `사업체`, `네트워크`, `명함`, `활동기록`, `일정`, `직원`, `설정` 시트가 자동으로 생깁니다.

## 2. 사이트 코드 붙여 넣기

1. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
2. 왼쪽 `Code.gs`에 적힌 내용을 모두 지우고, `dist/apps-script/Code.gs` 내용을 통째로 붙여 넣습니다.
3. 왼쪽 **파일 옆 + → HTML**을 누르고 이름을 `index`로 입력합니다. `.html`은 자동으로 붙습니다.
4. 새로 생긴 `index.html`의 내용을 모두 지우고, `dist/apps-script/index.html` 내용을 통째로 붙여 넣습니다.
5. 위쪽의 **저장(디스크 모양)** 아이콘을 누릅니다.
6. 왼쪽 위의 프로젝트 이름을 `아르딤 취업지원`으로 바꿉니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `첫 배포`
   - 다음 사용자 인증 정보로 실행: **웹 앱에 액세스하는 사용자**
   - 액세스 권한이 있는 사용자: **Google 계정이 있는 모든 사용자**
     (복지관이 구글 워크스페이스를 쓰면 조직 이름이 나온 항목을 고르세요)
4. **배포**를 누르고 권한 승인 창이 뜨면 관리자 계정으로 허용합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 아르딤 취업지원(으)로 이동**을 누르세요. 우리가 직접 만든 스크립트여서 나오는 안내입니다.
5. 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둡니다. 이 주소가 팀 공유 사이트입니다.

## 4. 팀원 초대하기

"웹 앱에 액세스하는 사용자" 권한으로 실행하기 때문에, **이 스프레드시트를 공유받은 사람만** 사이트를 쓸 수 있습니다.
주소가 밖으로 새어 나가도 공유받지 않은 사람은 데이터를 볼 수 없습니다.

1. 구글 시트 오른쪽 위 **공유**를 누릅니다.
2. 팀원 3명의 구글 계정 이메일을 넣고 권한을 **편집자**로 정합니다.
3. 3단계에서 복사한 웹 앱 URL을 팀원에게 보냅니다.

팀원은 주소를 열고 구글 로그인을 한 뒤, 처음 한 번만 권한 허용을 누르면 됩니다.

## 5. 처음 설정

1. 사이트를 열면 빈 화면으로 시작합니다.
2. **데이터 관리 → 담당 직원과 소속 사업**에서 4명의 이름과 소속(장애인개발원/고용공단)을 입력하고 저장합니다.
3. 각자 자기 PC에서 **데이터 관리 → 이 PC를 쓰는 사람**에서 본인 이름을 고릅니다. 활동 기록에 기록한 사람으로 남습니다.
4. 지금까지 파일 버전(`아르딤_취업지원.html`)에 입력한 데이터가 있다면 다음 순서로 옮깁니다.
   1. 파일 버전에서 **엑셀 내보내기**를 누릅니다.
   2. 공유 사이트에서 **엑셀 파일 선택**으로 그 파일을 가져옵니다.

## 쓰면서 알아둘 점

- 저장은 바로 구글 시트에 됩니다. 화면 위쪽에 `저장됨 10:32`처럼 표시됩니다.
- 다른 사람이 등록한 내용은 **1분마다**, 또는 다른 창에 있다가 **이 창으로 돌아올 때** 자동으로 반영됩니다.
- 두 사람이 같은 사업체를 동시에 고치면 나중에 저장한 내용이 남습니다.
- 구글 시트를 직접 열면 모든 데이터를 표로 볼 수 있습니다. 엑셀 파일이 필요하면 시트에서 **파일 → 다운로드 → Microsoft Excel**을 쓰면 됩니다.
- 시트의 **열 제목(1행)과 ID 열**은 고치지 마세요. 사이트가 데이터를 찾지 못합니다. 내용 칸을 시트에서 직접 고치는 것은 괜찮습니다.
- 명함 사진은 `명함사진` 시트에 글자 형태로 나뉘어 저장됩니다. 이 시트는 건드리지 마세요.
- 명함에는 외부 담당자의 개인정보가 들어갑니다. 스프레드시트 공유는 팀원에게만 하고, 복지관 개인정보 관리 지침을 확인해 주세요.

## 코드를 고친 뒤 다시 배포하기

1. Apps Script 편집기에서 `Code.gs`와 `index.html`을 새 내용으로 바꾸고 저장합니다.
2. **배포 → 배포 관리 → 연필(수정) 아이콘**을 누릅니다.
3. 버전을 **새 버전**으로 고르고 **배포**를 누릅니다.

이렇게 하면 웹 앱 주소는 그대로 유지됩니다.
