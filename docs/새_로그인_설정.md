# 새 로그인(구글 + 카카오) 설정 순서

바깥 사람도 가입 신청을 하고, 관리자가 받아 주면 들어오는 방식으로 바꾸는 설정이에요.
**아래를 모두 마치기 전까지 지금 앱은 예전 방식 그대로 동작해요.** (앱 설정 `webApp` 칸이 비어 있으면 새 방식이 꺼져 있어요)

## 무엇이 바뀌나

| | 지금 | 새 방식 |
|---|---|---|
| 로그인 | 복지관 구글 계정만 | 구글 계정 누구나 + 카카오 |
| 데이터 | 사람마다 구글 시트를 공유받아 직접 읽고 씀 | **서버(Apps Script)만 시트를 열고**, 사람마다 허용한 것만 보여 줌 |
| 바깥 사람 | 못 들어옴 | 가입 신청 → 관리자가 받아 줘야 들어옴 |
| 복지관 직원 | 바로 들어옴 | '받아 준 사람만 들어오기'를 끄면 바로, 켜면 신청 |

시트 원본은 서버만 열기 때문에, 바깥 사람을 받아 줘도 **이용자 개인정보가 든 시트를 직접 볼 수 없어요.**

## 1. Apps Script 서버 바꾸기 (관리자, 시트 주인 계정으로)

1. Apps Script 편집기 → 왼쪽 **프로젝트 설정(톱니바퀴)** → **"편집기에 'appsscript.json' 매니페스트 파일 표시"** 를 켜요.
2. 편집기로 돌아가 `Code.gs` 를 새 파일 내용으로 통째로 바꾸고, `appsscript.json` 도 새 내용으로 바꾼 뒤 **저장(Ctrl+S)**.
3. 지금 쓰는 배포 3개(API 실행 파일 포함)는 지난번처럼 **새 버전으로 배포** — 예전 방식이 계속 동작하게.
4. **배포 → 새 배포** → 유형 톱니바퀴에서 **웹 앱** →
   - 다음 사용자 인증 정보로 실행: **나**(시트 주인 계정)
   - 액세스 권한이 있는 사용자: **모든 사용자** (익명 포함)
   - **배포** → 권한 허용 창이 뜨면 모두 허용
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 알려 주세요. (비밀번호가 아니라 공개 주소예요)

> "모든 사용자"가 목록에 없으면 복지관 구글 워크스페이스 관리자가 바깥 공유를 막아 둔 거예요. 그 화면을 찍어 보내 주세요.

**시트 주인 계정이 열 수 있어야 하는 시트:** 팀 구글 시트, 고용지원 업무판 DB 시트, 복지관 사업실적 시트. 서버가 이 계정 권한으로 대신 열어요.

## 2. 카카오 로그인 준비 (카카오 개발자 사이트)

1. [developers.kakao.com](https://developers.kakao.com) 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (이름 예: 아르딤 로그인).
   **지도·장소 검색에 쓰는 카카오 앱과 따로** 만들어요. 로그인 버튼 주소에 앱 키가 보이기 때문이에요.
2. **앱 설정 → 플랫폼 → Web 플랫폼 등록** → 사이트 도메인 `https://ardim-jobs.web.app`
3. **제품 설정 → 카카오 로그인** → 활성화 **ON** → Redirect URI 에 `https://ardim-jobs.web.app/` (끝에 / 꼭)
4. **카카오 로그인 → 동의항목** → **닉네임** 을 '필수 동의'로
5. **카카오 로그인 → 보안** → Client Secret **코드 생성** → 활성화 상태 **사용함**
6. Apps Script **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - `KAKAO_REST_KEY` = 앱 키의 **REST API 키**
   - `KAKAO_SECRET` = 5번의 Client Secret 코드
7. **REST API 키**만 알려 주세요 (앱 설정에 넣어요). **Client Secret 은 채팅으로 보내지 마세요** — 스크립트 속성에만 넣어요.

## 3. 구글 로그인을 바깥 계정에도 열기 (구글 클라우드 ardim-jobs)

**4번(앱 전환) 바로 전에** 해 주세요. 미리 바꾸면 지금 방식에서 직원들에게 '확인되지 않은 앱' 경고가 뜰 수 있어요.

1. console.cloud.google.com → 프로젝트 **ardim-jobs** → **API 및 서비스 → OAuth 동의 화면**
2. 사용자 유형 **내부 → 외부** 로 바꾸기 → **앱 게시(프로덕션으로 푸시)**
3. 새 방식은 이름·메일만 받는 기본 로그인이라 구글 심사가 필요 없어요.

## 4. 앱 전환 (제가 해요)

1번 웹 앱 URL과 2번 REST API 키를 받으면 앱 설정에 넣고 올려요. 그 다음:

1. 관리자가 먼저 로그인해서 데이터 관리 → **사람·권한** 이 잘 열리는지 확인
2. 다른 계정(개인 gmail, 카카오)으로 가입 신청 → 관리자가 받아 주기 → 들어와지는지 확인
3. 확인되면 **'받아 준 사람만 들어오기'** 를 켤지 정해요
   - 끄면: 복지관 구글 계정은 바로, 그 밖(개인 구글·카카오)은 신청
   - 켜면: 모두 신청 (켤 때 지금 쓰는 사람과 이름이 등록된 계정은 자동으로 받아 둬요)
4. (권장) 모두 새 방식으로 쓰는 것이 확인되면, 직원들에게 공유돼 있던 **팀 구글 시트 공유를 풀어요.** 그래야 앱 밖에서 시트를 직접 여는 길이 닫혀요.

## 보안 메모

- 로그인 확인은 서버가 구글·카카오에 직접 물어서 해요. 화면이 보낸 이름·메일을 그대로 믿지 않아요.
- 서버는 30일짜리 서명된 출입증을 주고, 부를 때마다 명단·차단 여부를 다시 확인해요 (차단하면 바로 막혀요).
- 업무도구가 쓰는 시트는 업무판 DB 시트와 팀 시트의 '직업평가' 탭만 서버가 대신 열어요. 다른 탭은 메뉴 권한을 거쳐서만 보여요.
- 복지관 실적 시트는 데이터 관리에 정해 둔 시트만 열어요.
- 비밀값(카카오 Client Secret, 출입증 서명 열쇠)은 스크립트 속성에만 있고 화면·GitHub에는 없어요.
