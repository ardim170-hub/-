# 직업평가 기록지 코드 묶음

- 만든 곳: 화성시아르딤복지관 직업지원팀
- 기준일: 2026-11-17 (claude.ai에 올라가 있는 최신본을 그대로 복사)
- 원본 화면 주소: https://claude.ai/artifact/TRrq59C5d8jJXT2EoLjsbt (기관 공유)
- 들어 있는 것: `index.html` 한 파일 (화면 전체, 다른 파일 필요 없음)
- **참여자 기록은 들어 있지 않습니다.** 기록은 코드 밖(각 사용자 계정 저장소)에 저장됩니다.

---

## 1. 화면이 하는 일

대상자별로 직업평가 결과를 입력하면 표준점수·배치 수준을 계산하고, 직업평가 보고서 초안을 만들어 줍니다.

| 탭 | 내용 |
|---|---|
| 기본정보 | 이름, 장애명, 생년월일, 성별, 우세 손, 평가일, 평가도구 선택 등 |
| 기초인지 | 신상정보, 수 개념, 사칙연산, 색 개념, 방향, 시간, 읽기/쓰기 |
| BGT | 오류점수 → 표준점수 |
| MAND | 소근육·대근육 원점수 → 표준점수, 하위 지표(지속적 통제·근력·운동감각연합·양손민첩성) |
| HVDT | 오른손/왼손, 모양·크기·촉감·형태 → 표준점수 |
| 양손협응 | 다차원양손협응검사 원점수·백분율 |
| 관찰·소견 | 관찰 메모, 최종 프로그램 배치 수준 선택 |
| 보고서 | 보고서 칸별 작성 (Claude로 초안 쓰기 / 기본 문장 채우기 / 점수 갱신) |
| 완성본 | 읽기 전용 보고서, 전체 복사·텍스트 파일 저장 |

- 점수 변환표는 코드 맨 위 `const T = {...}` 에 들어 있습니다 (MDS 자동화 양식의 MAND·BGT·HVDT 변환표 기준).
- 보고서 문장 규칙(AI에게 주는 지시문)은 코드 뒷부분 `RSEC`, `DESC`, 프롬프트 만드는 부분에 있습니다.

## 2. 쓰는 기능 (claude.ai 아티팩트 기능)

| 이름 | 하는 일 |
|---|---|
| `db` | 대상자 기록 저장. 사람마다 따로 저장됨 (`data/users/<사용자ID>` 묶음) |
| `user` | 지금 연 사람이 누구인지 확인 (위 저장 위치를 정하는 데 씀) |
| `sample` | Claude에게 보고서 초안 받기 (`modelTier:'default'`) |
| `downloads` | 보고서 텍스트 파일 저장 |

- claude.ai 밖(일반 브라우저)에서 열면 기록은 그 브라우저에만 저장되고(`localStorage` 키 `vocEvalClients.v2`), Claude 버튼 대신 "채팅에서 받아 붙여넣기" 방식이 나옵니다.

## 3. 고칠 때 주의할 점

1. **기록은 사람마다 따로 저장됩니다.** 관리자님이 화면을 열면 관리자님 기록만 보이고, 기존 사용자의 기록은 보이지 않습니다(정상).
2. 저장 형식(대상자 기록의 칸 이름)을 바꾸면 이미 저장된 기록이 안 보일 수 있습니다. 칸을 지우거나 이름을 바꾸기 전에 먼저 상의해 주세요.
3. 원본 화면(위 주소)을 직접 고치면 **지금 쓰는 사람 화면이 바로 바뀝니다.** 시험은 사본으로 먼저 해 주세요.
4. 점수 변환표(`T`)는 검사 양식과 숫자가 맞아야 합니다. 바꿀 때는 원본 양식과 한 칸씩 대조해 주세요.

## 4. 편집 방법 두 가지

- **방법 A — claude.ai에서 편집 권한 받기:** 원본 화면 오른쪽 위 '공유(Share)' 메뉴에서 관리자님을 편집자로 추가합니다. 같은 주소를 계속 쓰므로 고친 내용이 모든 사용자에게 바로 반영됩니다.
- **방법 B — 이 파일로 새로 올리기:** `index.html`을 claude.ai(Claude Code 등)에서 새 아티팩트로 올리고, 위 2번의 기능 4개(`db`, `user`, `sample`, `downloads`)를 같이 선언합니다. 주소가 새로 생기며, 기존 사용자의 기록은 옮겨지지 않습니다.
