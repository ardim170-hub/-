# 구글 시트 "고용지원사업 참여자 관리 DB" 구조

- 1행은 머리글입니다. 기록은 2행부터 한 줄에 한 건입니다.
- **(자동)** 열은 머리글 칸에 넣은 수식(ARRAYFORMULA)이 채웁니다. 이 열에 값을 쓰면 수식이 깨지니 쓰지 마세요(쓸 때는 그 칸을 `null`로 건너뜀).
- 모든 기록 탭은 **등록번호**(참여자 탭 A열)로 이어집니다. 등록번호가 없는 분은 `임시-001` 같은 임시번호를 씁니다.
- 열을 끼워 넣으면 코드와 시트 안 수식(취업알선 자동 칸의 VLOOKUP 열 번호 등)이 어긋납니다.

## 탭 목록

| 탭 | 내용 |
|---|---|
| 안내 | 시트 쓰는 법 설명(사람이 읽는 탭) |
| 한눈에보기 | 등록번호를 고르면 한 사람의 기록을 모아 보여 줌(시트 안 화면) |
| 참여자 | 참여자 한 명당 한 줄 |
| 구직상담 | 직업상담기록지(초기 상담) |
| 과정상담 | 과정상담·사후관리 일지 |
| 서비스이력 | 받은 서비스·훈련·근무 이력 |
| 직무분석 | 사업체 직무분석(직무 하나당 한 줄) |
| 취업알선 | 알선·적합성 분석·결과 |
| 선택지 | 드롭다운 목록 |
| 장기근속자 | 장기근속자 명단(엑셀에서 통째로 불러옴) |
| 고용자원개발 | 새 구인 사업체 연락 기록 |
| 사업체관리 | 기존 사업체 관리 연락 기록 |
| 월별보고 | 월별 계획·결과보고 화면이 저장하는 글(JSON) |

## 참여자 (A~W)

| 열 | 머리글 | 비고 |
|---|---|---|
| A | 등록번호 | 없으면 `임시-NNN` |
| B | 성명 | |
| C | 성별 | 선택지 A |
| D | 생년월일 | |
| E | 연락처(본인) | |
| F | 보호자 연락처 | |
| G | 주소 | |
| H | 장애유형 | 선택지 B |
| I | 장애정도 | 선택지 C: `심한 장애(중증)` / `심하지 않은 장애(경증)` |
| J | 장애등록일 | |
| K | 수급 구분 | 선택지 D |

| O | 과정상담 횟수 | (자동) |

| V | 단계 메모 | |

## 구직상담 (A~AB) — 직업상담기록지

A 등록번호 · B 성명(자동) · C 작성일 · D 최종학력 · E 전공 · F 직업훈련(훈련원·직종·기간) · G 자격증·면허 · H 컴퓨터 활용 · I 외국어 · J 주요경력(사업체·직종·기간·퇴사사유) · K 희망업종 · L 희망직종 · M 희망근무지역 · N 희망임금(월, 만원) · O 입사형태 · P 희망 고용형태 · Q 희망 기업형태 · R 희망 근무시간 · S 기타 희망사항 · T 현재 직업상태 · U 가정환경(가족·동거·지지정도) · V 보장구 · W 장애원인 · X 주·부장애부위 · Y 복용약 · Z 건강문제(신체·정신·시각·청각·언어) · AA 종합소견 · AB 상담내용

- AB 상담내용에 '적합성 분석지에서 옮김'이 들어간 줄은 실적(직업상담 횟수)에서 뺍니다.

## 과정상담 (A~K)

A 상담일자 · B 등록번호 · C 성명(자동) · D 상담자 · E 상담장소 · F 내담자와의 관계 · G 상담목적(선택지 E: 직업상담·사후관리 등) · H 상담방법(선택지 F) · I 상담내용 · J 상담결과 및 지원계획 · K 수퍼비전

- G 상담목적이 '사후관리'인 줄이 사후관리 실적·다음 사후관리일 계산에 쓰입니다.

## 서비스이력 (A~H)

A 일자 · B 등록번호 · C 성명(자동) · D 구분(선택지 G) · E 서비스명·기관·사업체(선택지 H) · F 내용·직무 · G 종료일(퇴사일) · H 비고

## 취업알선 (A~U)

A 알선일 · B 등록번호 · C 성명(자동) · D 사업체·직무(직무분석 A열 값) · E 구직자 직업능력수준 · F 희망 고용형태(자동) · G 희망임금(자동) · H 희망근무지역(자동) · I 구인 고용형태(자동) · J 구인 임금(자동) · K 근무지·교통(자동) · L 적합성 비교·분석 · M 소견: 구직자 · N 소견: 사업주 · O 소견: 담당자 · P 작성자 · Q 결과(선택지 J: 취업·불합격·포기) · R 취업일 · S 퇴사일 · T 퇴사사유 · U 비고

- F~H는 구직상담 탭, I~K는 직무분석 탭에서 VLOOKUP으로 가져옵니다. D 값이 직무분석 A열과 글자까지 같아야 합니다.

## 선택지 (A~J) — 드롭다운 목록

A 참여자·성별 · B 참여자·장애유형 · C 참여자·장애정도 · D 참여자·수급 구분 · E 과정상담·상담목적 · F 과정상담·상담방법 · G 서비스이력·구분 · H 서비스이력·서비스명 · I 직무분석·근무형태 · J 취업알선·결과

- '취업'(J), '직업상담·사후관리·구직상담'(E)은 실적·단계 계산에 쓰여 이름을 바꾸면 안 됩니다.

## 장기근속자 (A~G)

A 근로자 · B 사업체명 · C 입사일 · D 장기근속 여부(O/X) · E 등록번호(자동, 참여자 이름과 맞춤) · F 비고 · G 불러온 날

## 고용자원개발 (A~H)

A 일자 · B 사업체명 · C 위치 · D 주작업(직무) · E 연락방법·내용 · F 채용의사(있음/검토 중/없음) · G 직무분석(완료/예정) · H 비고

## 사업체관리 (A~E)

A 관리일자 · B 사업체명 · C 업종 및 직무내용 · D 세부내용 · E 비고

## 월별보고 (A~D)

A 연월(예: 2026-11) · B 종류(계획/결과) · C 내용(화면이 쓰는 JSON, 직접 고치지 않음) · D 저장한 날
