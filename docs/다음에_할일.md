## 1. 네이버 지도 연결 (실험 기능은 이미 들어가 있음)
- 네이버 클라우드 콘솔 → Maps → Application 등록 → Dynamic Map 체크
- Web 서비스 URL에 사이트 주소 등록 (데이터 관리 → 🟢 네이버 지도 칸에 나온 주소 + https://script.google.com)
- Client ID를 데이터 관리 → 네이버 지도에 넣고 저장 (키 방식 ncpKeyId)
- 지도 화면 위쪽에서 네이버 / 나란히 비교 확인
- 인증 실패 시: 주소 등록 확인 → 몇 분 뒤 새로고침 → 그래도 안 되면 키 방식 ncpClientId로
