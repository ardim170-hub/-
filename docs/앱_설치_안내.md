# 휴대폰 앱(Firebase) 설치 안내

지금 사이트와 **같은 기능, 같은 데이터(구글 시트)**를 쓰는 휴대폰 앱이에요.
화면만 Firebase에 올리고, 데이터 저장·권한은 지금처럼 구글 시트와 Apps Script(Code.gs)가 맡아요.
지금 사이트(script.google.com 주소)는 그대로 쓸 수 있어요.

```
휴대폰 앱 (Firebase 호스팅, 무료)
   │  복지관 구글 계정으로 로그인
   ▼
Apps Script (Code.gs, 지금 것 그대로) ──▶ 구글 시트 (지금 것 그대로)
```

## 1. Firebase 프로젝트 만들기 (5분)
1. https://console.firebase.google.com → **프로젝트 추가** → 이름 예: `ardim-jobs` (애널리틱스는 꺼도 돼요)
2. 왼쪽 **빌드 > Hosting > 시작하기** (안내 화면은 '다음'만 눌러 넘겨요)
3. 프로젝트 설정(톱니바퀴)에서 **프로젝트 ID**와 **프로젝트 번호**를 메모해요

## 2. 구글 클라우드 설정 (10분) — 같은 프로젝트
https://console.cloud.google.com 에서 위쪽 프로젝트를 방금 만든 것으로 고르고:
1. **API 및 서비스 > 라이브러리** → `Apps Script API` 검색 → **사용**
2. **API 및 서비스 > OAuth 동의 화면**
   - 복지관 계정이 구글 워크스페이스면 **내부**, 아니면 **외부**(그리고 '테스트 사용자'에 팀원 메일 추가)
   - 앱 이름: 아르딤 직업지원팀, 지원 메일: 내 메일
3. **API 및 서비스 > 사용자 인증 정보 > 사용자 인증 정보 만들기 > OAuth 클라이언트 ID**
   - 유형: **웹 애플리케이션**
   - 승인된 자바스크립트 원본: `https://<프로젝트ID>.web.app`, `https://<프로젝트ID>.firebaseapp.com`
   - 승인된 리디렉션 URI: `https://<프로젝트ID>.web.app/`, `https://<프로젝트ID>.firebaseapp.com/` (끝의 / 포함)
   - 만들면 나오는 **클라이언트 ID**(…apps.googleusercontent.com)를 메모해요

## 3. Apps Script 연결 (5분)
구글 시트 > 확장 프로그램 > Apps Script 편집기에서:
1. **프로젝트 설정(톱니바퀴) > Google Cloud Platform(GCP) 프로젝트 > 프로젝트 변경** → 1번의 **프로젝트 번호** 입력
2. 같은 화면의 **스크립트 ID**를 메모해요
3. **배포 > 새 배포 > 유형 선택(톱니바퀴) > API 실행 파일**
   - 액세스 권한: **Google 계정이 있는 모든 사용자** (데이터는 시트를 공유받은 사람만 보여요)
   - 배포 → 나오는 **배포 ID**를 메모해요
4. 이후 Code.gs를 고칠 때마다: **배포 > 배포 관리 > API 실행 파일 ✏️ > 버전: 새 버전 > 배포**

## 4. 메모한 값 알려 주기
클라이언트 ID, 스크립트 ID, 배포 ID, Firebase 프로젝트 ID를 Claude에게 알려 주면 `web/config.js`에 넣어 올려요.
(비밀번호가 아니라 공개돼도 되는 값이에요.)

## 5. 자동 올리기 설정 (5분, 한 번만)
1. Firebase 콘솔 > 프로젝트 설정 > **서비스 계정 > 새 비공개 키 생성** → JSON 파일이 받아져요
   - ⚠️ 이 파일은 비밀번호예요. 채팅에 붙여넣지 말고, 아래 GitHub 칸에만 넣어요
2. GitHub 저장소 > **Settings > Secrets and variables > Actions**
   - **Secrets** 탭 > New repository secret: 이름 `FIREBASE_SERVICE_ACCOUNT`, 값: JSON 파일 내용 전체
   - **Variables** 탭 > New repository variable: 이름 `FIREBASE_PROJECT_ID`, 값: 프로젝트 ID
3. 이제 live 갈래에 올라갈 때마다 앱이 자동으로 새 버전이 돼요

## 6. 휴대폰에 설치
- **안드로이드**: 크롬에서 `https://<프로젝트ID>.web.app` → 로그인 → 아래 **📲 앱으로 설치** 버튼 (또는 ⋮ > 앱 설치)
- **아이폰**: 사파리에서 열기 → 공유(□↑) > **홈 화면에 추가**
- 처음 로그인할 때 구글이 시트·드라이브·캘린더 권한을 물어요 → **모두 허용** (지금 사이트가 쓰는 권한과 같아요)
- 로그인은 1시간마다 다시 확인해요. 이미 허용했으면 화면이 잠깐 깜빡이고 바로 돌아와요.

## 알아 둘 점
- 브이월드 지도 키를 쓰고 있다면, 브이월드 인증키 관리에서 서비스 URL에 `https://<프로젝트ID>.web.app` 도 추가해요.
- 인터넷이 끊겼을 때 입력한 기록은 휴대폰에 보관했다가 다시 연결되면 자동으로 저장돼요 (지금 사이트와 같음).
